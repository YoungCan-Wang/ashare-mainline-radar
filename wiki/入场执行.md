# 入场执行

入场执行把下一笔计划落成可检验的价格条件与挂单类型。数值计划由 `execution.build_trade_execution_plan` 生成；是否触发由 `entry_confirmed` 判定；纸面成交由 `paper_trading` 推进。

## 价格计划

以信号日收盘 `last_close` 为基准：

| 字段 | 公式 | 默认 |
| --- | --- | --- |
| `entry_mode` | 个股状态为 `突破观察` 时 `breakout_close_confirm`，否则 `pullback_close_reclaim` | — |
| `entry_zone_low` | `last_close × 0.955` | 四舍五入至分 |
| `entry_zone_high` | `last_close × 0.985` | 四舍五入至分 |
| `confirm_price` | `last_close × 1.012` | 四舍五入至分 |
| `stop_price` | `last_close × (1 − 0.08)` | 失效位 8% |
| `valid_for_days` | 信号日后等待确认的交易日数 | 5 |
| `max_hold_days` | 固定持有期 | 15（或回测持有期） |
| `max_position_fraction` | 单仓上限 | 0.25 |
| `initial_position_fraction` | 首笔 | 上限 / 3，即 1/12 |

下一笔文案另给出软失效：收盘的 95% 先降级观察。组合基准叙述为最多同时两仓。

未映射回踩复用同一公式，但仓位上限按闸门改为 0.12 或 0.06；位于回踩区时买入区可扩至 `last_close × 0.97`–`last_close × 0.995`。

## 收盘确认

`entry_confirmed` 在信号日之后的交易日逐日检验，OHLC 任一 ≤ 0 则不确认。

**突破确认**（`breakout_close_confirm`）：收盘 ≥ `confirm_price` 且收盘 ≥ 开盘（收阳）。

**回踩收盘站回**（`pullback_close_reclaim`）：当日高低点与买入区有交集（最低 ≤ 区上沿且最高 ≥ 区下沿），收盘 ≥ 区上沿，收盘 ≥ 开盘，且收盘 > `stop_price`。

确认日写入 `trigger_date`，计划进入 `triggered`，并生成工作挂单。确认日收盘价不作为当日买入价。

## 隔夜挂单

| 入场模式 | `working_order_type` | 建议购买价 | 说明 |
| --- | --- | --- | --- |
| 含 `breakout` | `market_on_open` | 无 | 次日开盘价市价挂单 |
| `pullback_close_reclaim`，或模式名含 `pullback` / `reclaim` / `zone` | `overnight_limit` | `entry_zone_high` | 次日隔夜限价挂单 |

突破模式在确认日后第一个交易日：

- 成交量为 0：状态 `cancelled`，事件 `entry_blocked`，原因 `suspension`；
- 封死涨停：`cancelled` / `entry_blocked` / `sealed_limit_up`；
- 其余：按开盘价成交，`price_basis=next_session_open`。

回踩限价自确认日后一日起，搜索至 `signal_date + valid_for_days`（与已有 K 线取小）：

- 当日停牌或封死涨停：跳过该日，继续等待；
- 开盘 ≤ 限价：按开盘成交，`overnight_limit_open`，理由 `price_improvement`；
- 最低 ≤ 限价 < 开盘：按限价成交，`overnight_limit`；
- 窗口结束仍未触及：`expired`，理由 `overnight_limit_not_tagged`，文案「确认后有效期内隔夜限价未成交」。

未触发确认且已过 `valid_for_days`：`expired`，文案「5个交易日内未触发」，事件理由 `entry_not_triggered`。

## 涨跌停识别

`price_limit_rate`：北交所 30%；沪深主板 ST / *ST 在 `2026-07-06` 前 5%、之后 10%；科创板 `688` 为 20%；创业板 `300` 在 `2020-08-24` 起 20%；其余主板 10%。封死涨停：最低与收盘均不低于涨停价 − 0.005 元且成交量 > 0。封死跌停：最高与收盘均不高于跌停价 + 0.005 元且成交量 > 0。

## 退出

已开仓计划按下列顺序请求卖出日：

1. 已记录 `exit_signal_date`：下一交易日开盘；
2. 收盘 ≤ `stop_price`：下一交易日开盘，理由「收盘跌破失效位」；
3. 持有满 `max_hold_days`：当日收盘，理由「固定持有 N 日」。

卖出日若停牌或封死跌停：事件 `exit_delayed`，顺延至下一可成交日，累计 `exit_delay_days`。主题退出：生产策略连续 2 日不在前三活跃主题则记退出信号；冻结对照策略为 3 日。watching / triggered 在主题连续退出时直接 `cancelled`。

A 股 T+1：影子账本当日买入 `sellable_shares=0`，`buy_dt < as_of` 后解锁。纸面净值标记按收盘估算可实现净收益，含卖出费用假设。

## 费用与滑点

纸面默认 `TradingCostModel.account_capital=1_000_000`。影子账户使用 `100_000`。买卖各加/减滑点 0.05%。券商净佣金万分之 2，单边最低 5 元。股票：证管费万分之 0.2；经手费在 `2023-08-28` 起万分之 0.341，此前万分之 0.487；过户费在 `2022-04-29` 起万分之 0.1，此前万分之 0.2；卖出印花税在 `2023-08-28` 起万分之 5，此前千分之 1。ETF / 名称含「基金」：免印花税、证管费、过户费，基金经手费万分之 0.4。

影子买入按整手：代码前缀 `688` 每手 200 股，其余 100 股。成交数量取现金、净值 × 首笔比例、净值 × 单仓上限三者中的可负担手数。
