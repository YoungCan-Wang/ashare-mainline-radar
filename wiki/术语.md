# 术语

本表收录白皮书与系统输出中的专用名。英文括注为代码字段或行业通用译名。

## 场次与日期

| 术语 | 定义 |
| --- | --- |
| 场次 | `daily_session` 返回的 `(session_date, after_close)`。身份按北京时间开收盘划分，不按日历零点。 |
| `post-close` | 收盘后场次。T 日 15:00 至下一交易日 09:30 之前，含隔夜与周末。 |
| `pre-close` | 收盘前场次。交易日 09:30 至 15:00 之前。 |
| `MARKET_OPEN` | 09:30（`Asia/Shanghai`） |
| `MARKET_CLOSE` | 15:00（`Asia/Shanghai`） |
| `as_of` | 时点截断日，`YYYY-MM-DD`。截断日线、情报、财务。 |
| `session_as_of` | 当前时刻所属场次日。CLI 默认 `--as-of`。 |
| `data_as_of` | 本次实际使用的日 K 最大时间戳对应的北京日期。影子账本按此日提交。 |
| `last_bar_date` | 最后一根可见 K 线日期；可经 `RADAR_LAST_BAR_DATE` / `DATA_AS_OF` 传入频率闸门。 |
| `signal_date` | 计划创建日，等于当时 `data_as_of`。 |
| `trigger_date` | 收盘确认日。 |
| `entry_date` / `exit_date` | 纸面买入 / 卖出成交日。 |
| `buy_dt` | 影子持仓买入日，用于 T+1。 |

## 闸门与结构

| 术语 | 定义 |
| --- | --- |
| 市场闸门 | `TradingGate`。全市场新仓约束。 |
| `level` | `red` / `orange` / `green`。 |
| `state` | `暂停新仓` / `只准试错仓` / `允许寻找买点`。 |
| 硬熔断 | 破位确认、系统性杀跌、或指数压力叠加广度恶化。 |
| 允许动作 | `allowed_actions` 字符串列表。 |
| `advance_ratio` | 扫描股票当日上涨占比。 |
| `decline_2pct_ratio` | 扫描股票当日跌幅 ≤ −2% 占比。 |
| 指数结构 | `MarketStructure`。三大指数均线、量价、高低点与三日破位。 |
| 破位确认 | ≥ 2/3 指数连续 3 日收盘低于 20 日线。 |
| 环境脉冲 | `MarketPulse`。配置环境组的强度与状态。 |

## 主线

| 术语 | 定义 |
| --- | --- |
| 主线 | 配置主题在当日的可交易轮动方向。 |
| 主题状态 | `主线成立` / `主线候选` / `轮动观察` / `弱势/等待`。 |
| 前三主线 | 分数排序前三；纸面活跃集再要求成立或候选。 |
| 广度 | 主题内 `ret_5d` 或 `ret_20d` 为正的成员占比。 |
| 成交热度 | 个股或主题的 5 日成交额均 / 20 日成交额均。 |
| 龙头带 | `leader_tape`，个股分前 25。 |
| 价格阶段 | `山顶高拥挤`（可带 `·业绩支撑` / `·兑现不足`）、`半山腰待验证`、`半山腰兑现`、`山谷待反转`、`结构轮动`、`阶段未确认`。 |
| 拥挤分 | `crowding_score`，价格位置与热度代理。 |
| 生命周期 | `扩散启动` / `主线确认` / `主线延续` / `主升加速` / `主线回踩` / `退潮预警` / `资金试探` / `弱势等待`。 |
| `started_at` / `confirmed_at` / `stage_since` | 本轮启动日、确认日、当前阶段起始日。 |
| `transition_age` | 距最近阶段切换的交易日数；≤ 2 为新切换。 |
| 随市主线 | `independence_status` 默认值。 |
| 逆势独立主线 | 弱市中广度、热度、相对强度与独立分同时达标。 |
| 未映射强势 | 主题篮子外的高分位强势发现，需人工归因。 |
| `scoring_symbols` | 主题评分专用成分，可窄于展示映射。 |

## 个股名单

| 术语 | 定义 |
| --- | --- |
| 强势股 | 前 4 条活跃主题内通过趋势与量能门槛的个股。 |
| 黄金坑 | 前三主线急跌后的坑位；阶段 `坑位形成` / `止跌确认`。 |
| 预期差 | 公告窗口 3 日价格与成交相对业绩的代理。 |
| `利好兑现风险` / `业绩价格共振` / `利空出尽观察` / `预期差未确认` | 预期差四态。 |
| 低位资金介入 | 60 日中低位且成交额均线抬升的观察池。 |
| 月线箱体 | 18–30 个月分位箱体蓄势。 |
| 未映射回踩 | 未映射强势上的 pullback/reclaim（回踩再站稳）计划。 |
| `buyable_now` | 未映射可买标记。 |
| `rocket_watch` | 单边推进、过程回撤 < 8%。 |
| `bj_ipo_speculative` | 北交所 K 线不足 60 根的上市脉冲。 |
| 涨跌停观察 | 收盘板态统计；追板与抄底通道关闭。 |

## 基本面

| 术语 | 定义 |
| --- | --- |
| `基本面兑现` | 财务分 ≥ 67 且四项质量均为正。 |
| `兑现待质量确认` | 财务分 ≥ 62。 |
| `基本面观察` | 财务分 ≥ 52。 |
| `基本面拖累` | 财务分 < 52。 |
| `未覆盖` | 无核心财务记录。 |
| PB | Price-to-Book，市净率，不作跨行业统一贵贱阈值。 |
| ROE | Return on Equity，净资产收益率。 |

## 入场与挂单

| 术语 | 定义 |
| --- | --- |
| `next_buy` | 下一笔条件化计划。 |
| `primary` / `alternatives` / `by_theme` | 全局首选、备选、分主题名单。 |
| `entry_mode` | `pullback_close_reclaim` 或 `breakout_close_confirm`。 |
| 买入区 | `entry_zone_low`–`entry_zone_high`。 |
| 确认价 | `confirm_price`。 |
| 失效位 | `stop_price`，默认信号收盘 × 0.92。 |
| `valid_for_days` | 确认等待期，默认 5 个交易日。 |
| `max_hold_days` | 固定持有期，默认 15。 |
| `overnight_limit` | 隔夜限价，限价为区上沿。 |
| `market_on_open` | 次日开盘市价。 |
| `suggested_buy_price` | 建议购买价，等于限价。 |
| `price_basis` | 成交价格来源：`next_session_open` / `overnight_limit_open` / `overnight_limit` / `session_close` 等。 |
| 封死涨停 | `sealed_limit_up`。 |
| 封死跌停 | `sealed_limit_down`。 |
| T+1 | 当日买入的股票次一交易日才可卖。 |

## 纸面与影子

| 术语 | 定义 |
| --- | --- |
| 纸面计划 | `radar_trade_plans` 行。 |
| `plan_key` | `{signal_date}:{symbol}:{strategy_version}`。 |
| `watching` | 等待确认。 |
| `triggered` | 已确认，挂单待成交。 |
| `open` | 已持仓。 |
| `expired` | 窗口结束未开仓。 |
| `cancelled` | 计划取消。 |
| `closed` | 已平仓。 |
| `theme_exit_days` | 主题连续不在前三的退出天数。生产 2，冻结对照 3。 |
| `is_shadow` | 冻结对照策略标记。 |
| 影子账本 | `shadow_account` / `shadow_positions` / `shadow_events` / `shadow_nav_daily`。 |
| `apply_shadow_day` | 单日现金、持仓、事件、净值的数据库事务。 |
| `fill_buy` / `fill_sell` | 影子成交。 |
| `skip_t1` / `skip_insufficient_cash` | 影子阻断。 |
| 伴随卡片 | 雷达作战卡之后发送的蓝色影子账户飞书卡。 |

## 运行

| 术语 | 定义 |
| --- | --- |
| Daily | 日报工作流及其场次幂等策略。 |
| `curated` / `universe` | 仅篮子 / 全市场扫描。 |
| 并发组 | `tickflow-api-${{ github.repository }}`，`cancel-in-progress: false`。 |
