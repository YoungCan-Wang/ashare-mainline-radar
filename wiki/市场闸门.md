# 市场闸门

市场闸门（trading gate）是全市场参与约束。系统先计算指数结构与个股广度，再输出颜色、状态、分数、首笔仓位上限与允许动作。实现见 `risk_gate.build_trading_gate`。

## 输入

| 输入 | 定义 |
| --- | --- |
| A 股宽基环境 | `market_context_groups` 中同名脉冲；分数与状态进入闸门理由 |
| 三大指数 | 宽基组前三只：`000001.SH`、`399001.SZ`、`399006.SZ` |
| 指数单日中位涨跌 | 上述三只有 `ret_1d` 时取中位数 |
| 扫描股票 | `.SH` / `.SZ` 个股；剔除指数成员及名称含 ETF、LOF、REIT、指数、基金、转债、退 的标的 |
| 上涨占比 | `advance_ratio`：扫描股票 `ret_1d > 0` 的比例 |
| 跌超 2% 占比 | `decline_2pct_ratio`：扫描股票 `ret_1d <= -0.02` 的比例 |
| 指数结构 | `market_structure.status` 与确认分 |

## 指数结构

指数结构（market structure）检查宽基前三只日线。单只指数至少 35 根 K 线，否则整组状态为 `结构数据不足`，确认分 35.0。实现见 `market_structure.build_market_structure`。

单只指数信号：

| 信号 | 规则 |
| --- | --- |
| 站上 5 日线 | 收盘 > MA5 |
| 站上 20 日线 | 收盘 > MA20 |
| 均线转强 | 收盘 > MA5 > MA10，且 MA5 高于前一日 MA5，MA10 不低于前一日 MA10 |
| 持续量价 | 收盘 > MA20，且（单日涨幅 ≥ 1.2% 且当日成交额 / 此前 20 日均额 ≥ 1.20，或近 3 日均额 / 此前 20 日均额 ≥ 1.05 且收盘 > MA10） |
| 高低点抬高 | 近 10 日最高 > 此前 10 日最高，且近 10 日最低 > 此前 10 日最低 |
| 连续 3 日破位 | 最近 3 个交易日收盘均低于各自当日的 20 日均线 |
| 假跌破收复 | 最近一日已回到 20 日线上方，此前两日中至少一日在下方 |

确认分（0–100）：

`20 + 15×站上5日线比例 + 20×站上20日线比例 + 18×均线转强比例 + 17×量价比例 + 15×抬高比例 + 8×收复比例 − 25×破位比例`

组状态按多数原则（比例 ≥ 2/3）：

| 状态 | 条件（按判定顺序） |
| --- | --- |
| 破位确认 | 破位比例 ≥ 2/3 |
| 右侧确认 | 量价、抬高、均线转强均 ≥ 2/3 |
| 上升趋势 | 站上 20 日线、均线转强、抬高均 ≥ 2/3 |
| 假跌破收复 | 收复比例与站上 20 日线均 ≥ 2/3 |
| 底部未确认 | 站上 5 日线与站上 20 日线均 ≤ 1/3 |
| 筑底观察 | 其余情形 |

## 硬熔断

硬熔断（hard risk）任一成立，闸门为红色：

1. 指数结构状态为 `破位确认`。
2. 系统性杀跌：上涨占比 ≤ 0.20 且跌超 2% 占比 ≥ 0.40。
3. 指数压力与广度同时成立。

指数压力（`index_stress`）任一成立：

- 三大指数中至少 2 只当日跌幅 ≤ −2%；
- 三大指数单日中位涨跌 ≤ −2%；
- 宽基脉冲状态为 `风险收缩` 且分数 < 40。

广度确认压力（`breadth_confirms_stress`）任一成立：

- 上涨占比缺失或 ≤ 0.35；
- 跌超 2% 占比 ≥ 0.35。

## 颜色、状态与允许动作

| 颜色 `level` | 状态 `state` | 首笔上限 `max_initial_position_fraction` | 允许动作 `allowed_actions` |
| --- | --- | --- | --- |
| `red` | 暂停新仓 | 0.0 | 管理已有仓位；执行减仓/退出纪律；观察黄金坑确认信号 |
| `orange` | 只准试错仓 | 1/3 | 等待触发后小仓试错；不追高；确认后再加仓 |
| `green` | 允许寻找买点 | 1/3 | 按触发条件分批；首笔不超过计划仓位 1/3；失效时退出 |

红色分数取宽基脉冲分，缺省 20.0。橙色取宽基脉冲分，缺省 45.0。绿色取宽基脉冲分。

橙色在未触发硬熔断后，任一成立即判定：

- 宽基脉冲缺失，或分数 < 55，或状态属于 `{风险收缩, 中性震荡}`；
- 三大指数单日中位涨跌 ≤ −1%；
- 指数压力成立；
- 上涨占比 < 0.48；
- 指数结构属于 `{结构数据不足, 破位观察, 底部未确认, 筑底观察}`。

其余情形为绿色。

## 闸门对下游的约束

| 下游 | 红色 | 橙色 | 绿色 |
| --- | --- | --- | --- |
| `next_buy` | 不输出 `primary` / `alternatives`，名单转入等待确认 | 按触发条件生成计划 | 按触发条件生成计划 |
| 黄金坑 | 动作一律「只观察，等待确认」 | 止跌确认可写「触发后可列入试错仓」 | 同橙色 |
| 未映射回踩 | 全部只观察，`buyable_now=false` | 可买仓位压缩为 6% / 2% | 可买仓位 12% / 4% |
| 月线箱体 | 动作前缀「市场闸门关闭，仅列观察」 | 动作前缀「市场只允许试错仓」 | 原文案 |
| 生命周期 | 仍报告扩散、回踩、退潮；闸门只约束参与 | 同左 | 同左 |

红色闸门不机械清空已有纸面持仓。已开仓计划继续按失效位、主线退出与持有期退出。
