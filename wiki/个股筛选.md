# 个股筛选

个股筛选在闸门与主线之后并行产出多张名单。只有强势股经由 `next_buy` 可写入纸面计划。其余名单写入日报、飞书与（部分）研究快照。

## 强势股

模块：`strong_stocks.build_strong_stock_report`。候选来自排序后前 4 条状态属于 `{主线成立, 主线候选, 轮动观察}` 的主题；主题内使用 `theme_candidate_symbols`。

当前强度门槛（`BASE_ENTRY_PROFILE` / `base`）：

| 字段 | 阈值 |
| --- | --- |
| 个股状态 | `主升确认` / `突破观察` / `趋势延续` |
| 5 日涨幅 | ≥ 2% 且 < 15% |
| 20 日涨幅 | > 3% |
| 成交热度 | ≥ 1.00 |
| 距 20 日高点 | > −5% |

历史信号与当前门槛共用 `base` 剖面，另要求历史信号分 ≥ 62，且 20 日涨幅 ≥ 3%。信号日下一交易日开盘进入，持有 `hold_days`（CLI 默认 15）后按收盘退出。候选综合分：个股分 × 0.62 + 主题分 × 0.23，再叠加胜率、均值与样本加成。

财务覆盖后：未覆盖扣 5 分；已覆盖按 `(财务分 − 55) × 0.16` 调整。预期差：`利好兑现风险` 再扣 8 分，`业绩价格共振` 加 3 分。最终按主题公平抽取，每主题保底 2 只，总数默认 12。

## 下一笔计划

模块：`next_buy.build_next_buy_report`。对强势股生成条件化计划，优先级 < 60 淘汰。可执行决策集合：

`优先候选，等待回踩` / `突破确认候选` / `优先候选，分批确认` / `主升加速，等待回踩`

红色闸门时 `primary` 与 `alternatives` 为空。决策受基本面、预期差、生命周期与价格阶段约束，例如 `利好兑现风险，等待筹码稳定`、`退潮预警，停止新仓`、`主升加速，禁止追高`。ETF 名称含 `ETF` 或 `基金` 时，不受「基本面未覆盖」禁入。

`by_theme` 保留前 4 条活跃主题（成立 / 候选 / 轮动观察）各最多 3 只，即使闸门关闭也列出等待名单。

已触发的纸面计划通过 `overlay_triggered_working_orders` 覆盖同代码等待卡：决策改为 `已触发`，`execution_status=triggered`，沿用原确认价与买入区。

## 黄金坑

模块：`golden_pit`。只扫描排序前三且状态为成立/候选、价格阶段不以 `山顶高拥挤` 开头的主题。排除 ETF、ST、指数、基金、转债、退市及北交所。

硬条件：

| 项目 | 阈值 |
| --- | --- |
| K 线 | ≥ 60 根 |
| 距 20 日高点回撤 | −20% ≤ 回撤 ≤ −4.5% |
| 中期 | 收盘 ≥ 60 日线的 97%；5 日涨幅不得 < −13% |
| 承接 | 放量承接、相对三大指数抗跌、或放量收复 10 日线，三者至少一项 |
| 底部确认分 | 5 日线走平/抬升、近 3 日不创新低、MACD 空头动能收缩，至少 1 项 |
| 派发否决 | 近 5 日均额 ≥ 此前 15 日均额 × 1.15，收盘 < MA10，且高低点继续下移 |
| 基本面 | `基本面拖累` 直接剔除 |
| 分数 | ≥ 62 |

阶段：放量收复 10 日线且底部确认分 ≥ 2 为 `止跌确认`，否则为 `坑位形成`。红色闸门或坑位形成时动作为「只观察，等待确认」。名单上限 8（引擎初筛可放大，财务后重算）。不写入纸面计划。

## 预期差

模块：`expectations`。对已公告财务记录，取公告日及随后最多 2 个交易日相对前收的涨跌，以及该窗口均额 / 此前 20 日均额。

强业绩：`基本面兑现`，或财务分 ≥ 72，或营收同比 ≥ 15 且净利润同比 ≥ 30。放量：窗口均额比 ≥ 1.08。

| 状态 | 条件 | 分 |
| --- | --- | --- |
| 利好兑现风险 | 强业绩 + 3 日反应 ≤ −3% + 放量 | 90 |
| 业绩价格共振 | 强业绩 + 3 日反应 ≥ +3% + 放量 | 85 |
| 利空出尽观察 | `基本面拖累` + 3 日反应 ≥ +3% + 放量 | 72 |
| 预期差未确认 | 其余 | 50 |
| 未覆盖 | 无公告或无法对齐 K 线 | — |

该信号是公告窗口价格成交代理，不等于卖方一致预期。完整扫描留在日报制品，角色 `expectation_gap` 不写入可执行研究池。

## 基本面

模块：`fundamentals`。仅对强势、低位、黄金坑、未映射种子及主题公司股拉核心指标。分数从 50 起，叠加营收同比、净利同比、年化 ROE、每股经营现金流符号及增速变化；负增长或负 ROE 设上限。

| 状态 | 条件 |
| --- | --- |
| 基本面兑现 | 分 ≥ 67 且营收、净利、ROE、经营现金流均 > 0 |
| 兑现待质量确认 | 分 ≥ 62 |
| 基本面观察 | 分 ≥ 52 |
| 基本面拖累 | 其余 |
| 未覆盖 | 无权限或无记录 |

PB（市净率）只作同业参考。无财务密钥时标记未覆盖，不阻断日报。

## 低位资金介入

模块：`accumulation`。沪深个股，排除 ETF / ST 等。同时满足：60 日位置 ≤ 0.58 或距 60 日高点回撤 ≤ −12%；5/20 或 10/30 成交额比分别 ≥ 1.08 或 1.04；5 日涨幅 ≥ −3%、20 日涨幅 ≥ −22%（若有）、收盘不低于近 10 日低点的 101%。分数 ≥ 58。

状态：`低位放量转强` / `低位资金试探` / `低位观察`。入场仍须文案中的站回或放量突破条件。财务未覆盖扣 4 分。不写入纸面计划。

## 月线箱体

模块：`monthly_base`。月 K 窗口 18 / 24 / 30 个月；上沿取高点 80 分位，下沿取低点 20 分位。入选：宽度 12%–65%，收盘容纳率 ≥ 82%，斜率绝对值 ≤ 0.025，净涨跌 ≤ 45%，上下沿各至少触碰 2 次，近 6 月均额 / 首 6 月均额 ≤ 1.30，现价在箱底 92% 至箱顶 118%，近 60 月前高 / 箱体中枢 < 2.20。

阶段：`初步突破` / `箱顶蓄势` / `箱底观察` / `箱体中部`。红色闸门只保留观察。不写入纸面计划。

## 未映射回踩

模块：`unmapped_pullback`。主题名固定为 `未映射强势`。种子为未映射强势榜，或同分位与 5/20 日、量能、高点约束的未映射股。约 60 日窗口内先推进 ≥ 15%，再自高点回撤 ≥ 6%，视为建设性回踩。过程回撤 < 8% 且距高点回撤浅于 4% 标为 `rocket_watch`。北交所 K 线不足 60 根标 `bj_ipo_speculative`。ST / *ST 与基金类剔除。

`buyable_now` 要求：风格 `pullback_reclaim`、非基本面拖累、正在收复或位于回踩区、分位 ≥ 80%、闸门非红色。橙色闸门下非回踩风格不可买；可买仓位上限 0.12 / 0.04，橙色为 0.06 / 0.02。名单上限 20，可买展示上限 5。只写入日报制品，不进入 `radar_symbol_selections`、报价扇出或纸面账本。

## 涨跌停观察

模块：`price_limit_watch`。统计当日触板、封板、炸板、天地板、跌停打开、地天板等收盘状态。追板与抄底通道保持关闭：`ceiling_verdict=关闭追板通道`，`floor_verdict=关闭抄底通道`。证据截至 `2026-08-12` 的可执行样本外期望为负。该通道不创建交易计划。
