# 主线识别

主线（mainline）是配置主题篮子在当日横截面上的可交易轮动方向。主题名单来自 `configs/theme_baskets.json`，由人工维护，东财概念只作篮子刷新源。实现见 `market.build_theme_snapshots`。

## 个股快照

每只可用日 K（收盘与成交额均不少于 20 根）生成 `SymbolSnapshot`。绝对分从 50 起算：

| 分量 | 公式 |
| --- | --- |
| 20 日涨幅 | `18 × clip((ret_20d − 0) / 0.20, −1, 1.5)` |
| 5 日涨幅 | `14 × clip(ret_5d / 0.10, −1, 1.5)` |
| 1 日涨幅 | `10 × clip(ret_1d / 0.05, −1, 1.5)` |
| 成交热度 | `12 × clip(amount_ma5 / amount_ma20 − 1, −0.8, 1.5)` |
| 20 日高位距离 | `8 × clip(1 + high_proximity_20d / 0.08, −1, 1)` |

个股状态 `classify_symbol`：

| 状态 | 条件 |
| --- | --- |
| 主升确认 | `ret_20d > 0.12` 且成交热度 > 1.25 |
| 突破观察 | `ret_5d > 0.04` 且距 20 日高点 > −4% |
| 趋势延续 | `ret_20d > 0` 且成交热度 > 0.9 |
| 短线降温 | `ret_5d < −0.05` |
| 中性 | 其余 |

全市场股票（`.SH` / `.SZ` / `.BJ`，剔除 ETF 等）再做横截面归一：`score = clip(绝对分 × 0.70 + 分位 × 0.28, 0, 99.5)`，并写入 `relative_percentile`（0–100）。

## 主题评分

评分成员优先使用主题的 `scoring_symbols`；缺省回退映射符号。主题绝对分从 45 起算：

| 分量 | 上限或系数 |
| --- | --- |
| 20 日广度 | `20 × breadth_20d` |
| 5 日广度 | `12 × breadth_5d` |
| 20 日均涨幅 | `14 × clip(avg_ret_20d / 0.16, −1, 1.5)` |
| 5 日均涨幅 | `8 × clip(avg_ret_5d / 0.08, −1, 1.5)` |
| 成交热度 | `10 × clip(amount_heat − 1, −0.8, 1.4)` |
| 非政策情报 | `min(6, 条数 × 1.2)` |
| 政策分 | `min(8, policy_score × 0.08)` |
| 前三龙头 | `clip((前三均分 − 60) / 10, −4, 6)` |

随后混入当日主题横截面分位：`score = clip(绝对分 × 0.90 + 分位 × 0.10 − 集中度扣分, 0, 99.5)`。成员数 ≥ 4 且最强成员占正 20 日收益贡献超过 35% 时，扣分 `clip((集中度 − 0.35) × 20, 0, 8)`。

主题状态 `classify_theme`：

| 状态 | 条件 |
| --- | --- |
| 主线成立 | 分数 ≥ 78 且 20 日广度 ≥ 0.58 |
| 主线候选 | 分数 ≥ 68 且成交热度 ≥ 1.05 |
| 轮动观察 | 分数 ≥ 58 |
| 弱势/等待 | 其余 |

日报「前三主线」取排序后的前三名，且状态属于 `{主线成立, 主线候选}` 时计入纸面活跃主题集。

## 价格阶段

价格阶段是 60 日位置、涨幅、广度与成交的拥挤代理，不表示机构持仓。拥挤分：

`55 × 60日均位置 + 25 × 20日广度 + 20 × clip((成交热度 − 0.8) / 0.7, 0, 1)`

| 阶段 | 条件 |
| --- | --- |
| 山顶高拥挤 | （60 日均涨幅 ≥ 40% 且位置 ≥ 0.65，或位置 ≥ 0.78 且 60 日均涨幅 ≥ 18%）且拥挤分 ≥ 68 |
| 山谷待反转 | 位置 ≤ 0.35，或 60 日均涨幅 ≤ −15% |
| 半山腰待验证 | 状态为成立/候选，且 0.35 < 位置 < 0.78 |
| 结构轮动 | 其余（位置已知） |
| 阶段未确认 | 60 日位置缺失 |

财务覆盖后：半山腰在平均财务分 ≥ 62 且兑现成员占比 ≥ 40% 时改为 `半山腰兑现`；山顶高拥挤按财务分 ≥ 67 且兑现占比 ≥ 50% 分为 `山顶高拥挤·业绩支撑` 或 `山顶高拥挤·兑现不足`。

## 生命周期

系统回放约 45 个交易日（覆盖率至少标的数的 35%）重建主题状态序列。成员数 < 4 的历史截面不记点。实现见 `theme_lifecycle`。

单日原始阶段：

| 原始阶段 | 条件 |
| --- | --- |
| 主升加速 | 5 日广度 ≥ 0.72，20 日广度 ≥ 0.58，5 日均涨 ≥ 5%，20 日均涨 ≥ 3%，成交热度 ≥ 1.08 |
| 回踩态 | 当日状态为主线成立，且（5 日广度 < 0.45 或 5 日均涨 ≤ 0） |
| 主线确认 | 当日状态为主线成立且 20 日均涨 > 0 |
| 扩散启动 | 5 日广度 ≥ 0.60，5 日均涨 ≥ 1.5%，成交热度 ≥ 1.03 |
| 资金试探 | 5 日广度 ≥ 0.50，5 日均涨 > 0，成交热度 ≥ 1.0 |
| 弱势等待 | 其余 |

对外阶段含 `主线延续`、`主线回踩`、`退潮预警`。已确认主线的回踩态：连续 ≤ 5 日为 `主线回踩`，6–7 日为 `退潮预警`，之后回到弱势。`主线确认` 改名为 `主线延续` 时保留原确认日为 `stage_since`。`弱势等待` 不输出信号。`transition_age ≤ 2` 视为新切换。

市场闸门关闭时仍输出生命周期，闸门只约束参与动作。

## 逆势独立主线

闸门为橙色或红色时，对活跃阶段 `{扩散启动, 主线确认, 主线延续, 主升加速}` 计算独立分。独立分同时满足下列条件时，`independence_status` 为 `逆势独立主线`，否则为 `随市主线`：

- 5 日广度 ≥ 0.60，20 日广度 ≥ 0.50，成交热度 ≥ 1.03；
- 主题 5 日均涨 − 全市场个股 5 日收益中位数 ≥ 3%；
- 独立分 ≥ 68。

独立分构成：广度、热度、相对强度、主题分、政策分；拥挤分 ≥ 80 时扣 15。逆势独立主线在下一笔计划中只按试错仓处理。

## 环境脉冲

`market_context_groups` 生成 `MarketPulse`。配置组包括：A 股宽基环境、券商风险偏好、科技成长映射、外围科技映射、防御红利环境、消费景气环境、新能源产业环境。脉冲状态：

| 状态 | 条件 |
| --- | --- |
| 风险偏好转强 | 分数 ≥ 72 且 20 日均涨 > 0 |
| 结构性友好 | 分数 ≥ 60 且 20 日上涨成员占比 ≥ 0.5 |
| 中性震荡 | 分数 ≥ 46 |
| 风险收缩 | 其余 |

第一脉冲状态属于 `{风险偏好转强, 结构性友好}` 时，下一笔优先级加 2 分。

## 情报与政策

非政策情报按主题关键词计入 `catalyst_count`。政策条目需带标签集合 `{policy, official_policy, state_council, ministry, regulator, macro_policy}` 之一，并命中主题 `policy_keywords`。单条政策权重：国务院 +1.5、监管 +1.0、部委 +0.8、宏观政策 +0.5，再乘 18 累加，主题政策分上限 100。政策分只作主题加分与证据，单独存在时不构成买入理由。

## 龙头带

`leader_tape` 按个股归一后分数取前 `leader_limit` 名，默认 25。写入日报与飞书，角色为 `leader_tape`，不进入纸面计划。

## A/H 观察

`cross_market` 按主题港股通篮子与同公司 A/H 配对输出 `A港共振`、`港股领先`、`A股领先`、`A港共同走弱` 等观察。该模块不提高 `next_buy` 分数。

## 未映射强势

全市场模式下，无主题映射且横截面分位 ≥ 80%、5 日涨幅 > 2%、20 日涨幅 > 5%、成交热度 ≥ 1.0、距 20 日高点 > −8% 的公司股进入未映射发现榜，上限 20。发现项需人工归因后才能升级为主线。
